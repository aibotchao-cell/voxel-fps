# VOXEL FACTORY — 廢棄工廠 第一人稱射擊

Minecraft 方塊風格的網頁 FPS，用 **Three.js** 寫成，**iPad Safari 直接開就能玩**（純觸控）。

## 怎麼玩（iPad）

### 方法 A：線上通道（推薦，免設防火牆、不同 Wi-Fi 也能玩）
1. 電腦上雙擊 **`start-online.bat`**
2. 視窗裡會出現一行 `https://xxxx.trycloudflare.com`
3. iPad **Safari** 打開那個網址 → 開始遊戲
> 注意：每次重開通道，網址都會換一組。PC 要開著、視窗不能關。

### 方法 B：同一個 Wi-Fi 直連（需先處理防火牆）
1. iPad 和 PC 連**同一個 Wi-Fi**
2. 雙擊 **`start-server.bat`**
3. iPad Safari 開 `http://192.168.0.13:8000`
> ⚠️ 本機 IP 直連會被 Windows 防火牆擋（此機器 Wi-Fi 被歸類為「公用網路」且有 python 封鎖規則）。
> 若要用這招，需以**管理員**身分執行：
> ```powershell
> Set-NetConnectionProfile -InterfaceAlias "Wi-Fi" -NetworkCategory Private
> Remove-NetFirewallRule -DisplayName "python.exe"
> New-NetFirewallRule -DisplayName "VoxelFPS 8000" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8000
> ```
> 且建議**固定 PC 的區網 IP**（路由器設 DHCP 保留），否則 IP 會變。

## 目標：無盡關卡（場景每 5 關循環，難度一輪一輪往上疊）
每一關是**完全不同的場景佈局**，而且各有自己的**氣氛（天空色／霧／燈光）**。5 種場景會一直循環（第 6 關＝第 1 關的場景，但更難），敵人數、血量、準度、傷害都隨輪數上升：

| 場景 | 名稱 | 敵人數（第 1 輪） | 佈局 | 氣氛 |
|------|------|------|----------|------|
| 1 | 工廠大廳 | 10 | 開闊大廳、柱子、箱堆，視野最長 | 灰塵白天 |
| 2 | 裝配車間 | 15 | 多條**輸送帶**橫貫全場 + 綠色機台，走道多 | 冷灰藍 |
| 3 | 鍋爐房 | 21 | **狹窄房間與走廊**、鍋爐、管線柱，矮天花板 | 悶熱紅、霧很近 |
| 4 | 倉庫區 | 28 | **高架貨架**排成走道（迷宮感）| 塵土暖色 |
| 5 | 控制室 | 36 | **多層結構**：地面 + 高架平台 + 木箱階梯 + 辦公室 | 冷藍夜晚 |

**難度疊加規則**（第 N 輪，N 從 1 起算）：**人數完全不變**（每個場景永遠是它自己那個數字：10 / 15 / 21 / 28 / 36，上限 36 隻），
後面的關卡**只靠敵人變強**：血量 ×(1+0.18×輪數)、傷害 ×(1+0.14×輪數)、準度 +0.035×輪數（上限 0.92）、射速加快、跑速微增、視野變遠。
所以第 45 關還是 36 隻，但每隻都硬到不行、又快又準。

- **對手是「拿槍的人」**：人形（膚色頭、戰術背心、雙手持槍），會**開槍射你**（黃色曳光彈，可閃躲）。
- 他們會巡邏 → 看到你（有視線判定）→ 拉近距離 → 站定開火。
- 清空一關 → 等 2.4 秒自動進下一關（**滿血、彈藥補滿**）。
- 血歸零 → 2 秒後原地重生（同一關繼續），**重生後 5 秒內完全不會受傷**（HUD 左下方會出現「🛡 無敵 N 秒」倒數、畫面也會提示「重生！5 秒內不會受傷」），所以不會一重生又被秒。**每一關開始時也一樣有 5 秒**，讓你有時間看清楚環境。隊友重生同樣有 5 秒保護。
- **🤝 你有一個隊友**（藍色衣服 + 頭上有藍色標記）：會跟著你跑、**自動幫你射敵人**（藍白色曳光彈）、也會被敵人子彈打到。他陣亡後約 4 秒會在你身邊復活。左上 HUD 的藍色數字就是他的血量（陣亡時顯示「陣亡」）。

## 💀 每 10 關一隻 BOSS
第 **10、20、30…** 關是 BOSS 關（沒有第 5 關的終點，可以一直打上去）：

- 場景維持不變，但**整個關卡變成血紅色氣氛**（天空、霧、燈光全部轉紅），壓迫感很足。
- 關卡裡只留**少量小兵（3～6 隻）**，中間站著**巨型機甲 BOSS**（比人高 2.5 倍以上）：
  - 名稱與血量：第 10 關「鋼鐵廠長」**10000 血** → 第 20 關「熔爐巨獸」12500 → 第 30 關「鐵衛團長」15000…（血量超厚，是一場持久戰）
  - 行為：慢慢逼近 → **四連發機砲**（後面的 BOSS 變 5、6 連發）→ 每 **5.8 秒暴衝**貼近你（跑速 5.2，比你沒升級時快一點）→ 每 **13 秒召喚 2 隻小兵**（總數上限 6 隻不變，會提示「BOSS 召喚了增援！」）
  - 傷害：**每發子彈 −40 血**（玩家內建 100 血 → 被命中 3 發就倒，買「防彈背心」+25 可以多撐幾發）；開火間隔 1.22 秒、準度 0.86 → 越後面的 BOSS 越準（上限 0.94）
  - 畫面上方會有**專屬血條**（名字 + 血量數字，血越少越紅），雷達上 BOSS 是**大顆紅點 + 呼吸光圈**
- 打贏 BOSS：**+$500**（一般關卡是 $100～$200），然後照樣繼續下一關。
- BOSS 血超厚（**10000 起跳**），打法是**躲掩體**：BOSS 看不到你就不會開槍，探頭打幾發再縮回去最安全（繞柱子、站高台）。帶**步槍／機槍**（子彈無限、只要換彈）打最順，**狙擊槍 67 發、火箭筒 129 發、火焰噴射器燒約 100 秒**。

## ⏸ 暫停與存檔（進度存在這台電腦）
### 怎麼暫停
- **iPad**：螢幕**下方中間**的 ⏸ 按鈕（不會撞到開火／跳／換彈，兩手都按得到）
- **電腦**：**Esc** 或 **P**
- 暫停時：敵人、子彈、計時全部**凍結**（畫面還在，只是不再更新），觸控按鈕會收起來
- **切到別的 App / 分頁會自動暫停**（並先存一次），所以不會回來發現自己被打死

### 暫停選單有 3 顆按鈕
| 按鈕 | 作用 |
|------|------|
| 💾 **儲存進度** | 手動存一次（其實不按也會自動存） |
| 🏠 **回主選單（進度保留）** | 先存檔再回主畫面，下次可以「繼續上次進度」 |
| 🆕 **放棄並重新開始** | **要點兩次**才生效（避免 iPad 誤觸）：清掉存檔、能力歸零回主選單 |

### 自動存檔時機
**每關一開始**、**離開補給站／進下一關**、**按暫停**、**切到別的 App** 都會自動存一次。

### 存檔存在哪裡
- 主要存在**這台電腦**：`save.json`（由 `serve.py` 的 `/api/save` 寫入）→ 所以 **cloudflared 網址換掉也不會不見**，iPad 和電腦看到的是同一份進度。
- 另外在**瀏覽器 localStorage** 也留一份備份；兩份都有時會用**時間比較新**的那份。
- 開場主選單會自動讀存檔：有進度時主按鈕變成「**▶ 繼續上次進度（第 N 關 · $M）**」，下面多一顆「🆕 新遊戲（清除存檔）」。
- 存檔內容：**關卡進度、金錢、擊殺數、已買的槍、強化後的數值（傷害／射速／彈匣／最大生命／跑速）**。
- ⚠️ 小提醒：通道網址是公開的，知道網址的人理論上可以讀寫這個存檔（家用遊戲沒差，但要記得這件事）。

## 📡 敵人雷達（左上角圓形小地圖）
- **會跟著你轉**：雷達上方永遠是你正面朝向，正中間白色三角 = 你自己。
- **紅點 = 敵人**（越近點越大）；**藍點 = 隊友**。
- **貼在圓圈邊邊的紅三角**＝那個方向的敵人還在雷達範圍（34 格）外，照著方向去找就對了（專治「找不到最後幾隻」）。
- **紅點旁的黃色小箭頭 ▲／▼** = 那個敵人比你高／低一層樓（有多層走道的關卡很有用）。
- 灰色平面圖 = 你這一層的牆與貨架，所以看得到走道與房間形狀。
- 每 3 個畫面更新一次，幾乎不吃效能。

## 🔍 狙擊槍放大鏡
- 在補給站買了**狙擊槍**後，「開火」鍵左邊會多一顆 **🎯 瞄準**。
- **iPad**：點一下開鏡、再點一下關鏡（做成切換式，因為單手沒辦法同時按住瞄準+開火）。
- **電腦**：按住**滑鼠右鍵**或 **Shift** 開鏡，放開就關。
- 開鏡時：視野從 78° 拉近到 **20°（約 4 倍）**、畫面變成圓形鏡筒＋十字準星＋紅色中心點＋下方刻度、手上的槍會收起來不擋視線。
- 開鏡時**轉視角靈敏度自動降到 26%**，所以可以慢慢微調瞄準；切換到別的武器會自動關鏡。

## 檔案結構

  world.js     世界資料 + 方塊網格化 + 碰撞查詢 + 5 種不同關卡佈局（buildLevel）
  textures.js  程序化產生的方塊材質圖集（無需外部圖檔）
  player.js    第一人稱移動、重力、AABB 碰撞、階梯

## 🌍 分享給朋友
三種做法，差別在「網址固不固定」和「要不要開這台電腦」：

| 做法 | 網址 | 需要 | 存檔 |
|------|------|------|------|
| **A. 部署到免費靜態空間**（推薦） | 固定（例：`xxx.netlify.app` / `xxx.pages.dev`） | 免費帳號（Netlify / Cloudflare / GitHub） | 存在**各人自己的瀏覽器**，進度互不干擾 |
| **B. cloudflared 臨時通道** | `https://隨機.trycloudflare.com`，**重開就換** | 這台電腦＋通道要一直開著 | 存在**這台電腦的 save.json** → ⚠️ 大家會**共用同一份進度** |
| **C. 直接把 zip 傳給朋友** | 沒有 | 朋友要自己會開本機伺服器（不推薦） | 各自瀏覽器 |

**做法 A 的步驟**
1. `python share_export.py` → 產生 `../voxel-fps-share/`（1.5 MB）與 `../voxel-fps-share.zip`（約 320 KB）
   （只會打包 index.html / styles.css / js / vendor / README，不會夾帶 cloudflared.exe 或存檔）
2. 把資料夾或 zip 拖到 <https://app.netlify.com/drop>（不用裝任何東西），或上傳到 Cloudflare Pages / GitHub Pages
3. 拿到固定網址就傳給朋友；朋友用手機、平板、電腦開瀏覽器就能玩，不用安裝
4. 之後改了遊戲，再跑一次 `share_export.py` 重新上傳即可

> 靜態空間沒有 `/api/save` 這支 API，遊戲會**自動退回存在瀏覽器 localStorage**（暫停面板會顯示「已存在瀏覽器」），
> 所以「繼續上次進度」照樣能用，只是進度跟著那台裝置／那個人。
